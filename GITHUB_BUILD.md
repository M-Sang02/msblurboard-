# GitHub build

Extract this ZIP and upload its contents to the root of a new GitHub repository. Do not upload the ZIP as a single file. The included GitHub Actions workflow builds a debug APK automatically on push or manually from Actions.

Toolbar follows the HeliBoard Debug model: Expandable, Toolbar keys only, Suggestions only, Hidden; separate clipboard toolbar keys; editor actions (select/copy/cut/paste); quick pinning; auto show/hide; physical-keyboard toolbar-only mode; and variable toolbar direction.
